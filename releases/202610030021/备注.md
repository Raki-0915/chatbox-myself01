## 本版改动（相对 202610022352）
### 世界书 + 人物卡共通（设置 → 创作资料）
1. **多选**：点选卡片（可多张）→ 顶部批量操作条：
   - **移动到指定文件夹**（下拉选择，清空=移出文件夹）
   - 启用 / 停用 / 删除 / 退出多选
2. **导出**：当前列表导出 JSON（复用官方 exporter，走系统分享面板）
3. **导入**：选择 JSON 文件合并导入（同 id 覆盖更新，无 id 新建）

### 人物卡「合并同名」
4. 点击「合并同名」→ 检索**姓名完全相同**的卡，分组列出
5. 选择组合 → **冲突字段逐项列出**（年龄/性别/职业/外貌/身高/体重/特征/性格/优缺点/爱好/背景/启停/文件夹/关系/自定义属性），每项可选择保留「卡1/卡2/…」的值
6. **关系、自定义属性支持「合并去重」**（多卡条目去重合并）
7. 底部「合并后删除旧卡」开关（默认开，保留卡1）→ 合并完成
