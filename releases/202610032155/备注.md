## 本版改动
1. 设置 → 标签「小说分章」改名「**小说续写**」
2. 新增「**续写要求（可选）**」输入框：续写时指定写到哪/什么情节，模型按要求续写（复用 v27Continue 的 extra 参数，此前 UI 未暴露）
3. 主操作重排：`切章 / 续写一章（主色）/ 推入小说会话`
4. 「生成改写方案 / 按方案改写末章」降级至「高级」分隔区保留
5. 续写完成后自动清空续写要求，提示可继续续写或推入会话

## 验证建议
- 设置 → 小说续写：粘贴含 多章标题 的正文 → 切章 → 章节预览出现各章
- 填写续写要求（如"这一章写到主角抵达长安城"）→ 续写一章 → 末章后追加新章且内容贴合要求
- 推入小说会话 → 侧边栏出现"小说·书名"会话
- 高级区：生成改写方案 → 点方案卡片 → 末章被按方案重写
