## 本版改动
1. **硅基流动（SiliconFlow）余额查询**：设置/导出 → 硅基流动区，粘贴 API Key → 查询余额 → 显示总余额/可用余额（GET /v1/user/info）；Key 仅本地保存
2. **世界书标准格式导入**：识别酒馆 World Info JSON（keys/content/constant/insertion_order/enabled）与 CSV（header / 传统无 header 4~6 列），映射到关键词/常驻(depth0)/深度/顺序；本项目导出包（无 keys）不误判
3. **注入体积自适应**：对话越长注入预算越小（base - 对话字数/4，保底 800），常驻设定优先、场景占剩余，防长对话上下文被设定挤爆
4. **%keywords% 通配递归**：世界书关键词写 %条目名% 可引用其他条目，命中后递归拉入被引用条目（深度≤3、visited 防环、常驻不参与场景递归）；%引用% 不参与普通关键词匹配
